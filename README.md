## 실행
Python 3에서 개별 문제 파일을 실행하고 문제의 입력 형식에 맞게 표준 입력을 제공합니다.

```sh
python "class2/FizzBuzz.py"
```

로컬에 입력 파일을 준비했다면 macOS/Linux 또는 명령 프롬프트에서:
```sh
python "class2/FizzBuzz.py" < input.txt
```

## 기록을 읽는 방법
파일명의 `2`, `_2`, `ver` 등은 별도 풀이·시도 기록입니다. 자동으로 최종 정답이나 더 빠른 구현이라는 뜻은 아닙니다. 예를 들어 `문자열집합.py`는 현재 빈 파일입니다. 각 파일을 독립적으로 확인하세요.

기하 폴더는 Windows에서 사용할 수 없는 `:` 문자를 제거해 `geometry/`로 변경했습니다. 풀이 코드의 바이트와 문제별 자동 업로드 경로는 유지했습니다.
